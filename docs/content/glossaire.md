# Glossaire

| Terme | Définition |
| --- | --- |
| Carreau | maille de 200 m × 200 m (4 ha) de la grille commune à toutes les couches |
| Part bâtie | fraction du carreau couverte de bâti (0 à 100 %) une année donnée |
| WSF 2019 / WSF Evolution | produits du DLR : surface bâtie 2019 à 10 m ; année d'urbanisation 1985-2015 à 30 m |
| Composite de saison sèche | médiane des observations Sentinel-2 claires d'août à décembre |
| Score de bâti | NDBI − NDVI d'un pixel |
| Calibration | choix du seuil de bâti tel que Sentinel-2 retrouve la surface de WSF 2019 sur le voisinage habité |
| Seuil de bruit (τ) | changement minimal retenu, mesuré sur les carreaux jamais habités |
| Régression isotone | ajustement d'une série non décroissante (courbe de croissance d'un carreau) |
| Population légale | population municipale publiée par l'INSEE pour un millésime (en vigueur trois ans plus tard) |
| Modèle dasymétrique | répartition d'une population sur les zones bâties plutôt qu'uniformément |
| Hypothèse communale | estimation de population saisie par la commune, affichée à côté du chiffre officiel |
| Rayon de desserte | distance à vol d'oiseau en deçà de laquelle un habitant est considéré desservi |
| Demande | habitants ou enfants de l'âge concerné d'un carreau |
| Couverture maximale | choix des sites qui desservent le plus de demande non desservie |
| RIL | répertoire d'immeubles localisés, base de sondage du recensement des communes ≥ 10 000 habitants |
| Recensement Éclaireur | liste des carreaux en croissance à signaler à l'INSEE avant la collecte |
| Instantané | copie embarquée des données et analyses pour fonctionner hors ligne |
