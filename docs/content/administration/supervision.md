# Supervision technique

Administration → **Supervision technique** (actualisée toutes les 15 s, aucun appel externe) :

- **Sources externes** : statut (ok, dégradé, indisponible après 3 échecs consécutifs), ancienneté du dernier succès, dernière erreur.
- **Analyses** : en cours, durée moyenne, échecs récents, dernières analyses.
- **API** : temps de réponse p50 / p95 par domaine, erreurs.
- **Base et stockage** : moteur, taille, nombre de lignes par table ; tailles du cache, des données et des sauvegardes ; espace disque libre ; fraîcheur des jeux de données.
