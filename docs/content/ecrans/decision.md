# Aide à la décision

1. **Besoin** : famille d'équipement, nombre de sites, rayon (défaut de la famille). La demande prise en compte est indiquée (enfants de l'âge concerné pour les établissements scolaires, habitants sinon).
2. **Contraintes** : plans d'eau, aires protégées, part bâtie maximale du carreau, distance maximale à une route, hypothèse communale de population.
3. **Proposer** : la carte montre l'accessibilité actuelle, les équipements existants (avec la demande rattachée à chacun) et les sites proposés, numérotés, avec leur cercle de desserte.
4. Pour chaque site : la demande nouvellement desservie, le **pourquoi ici**, les vérifications (ok / attention / non vérifié).
5. **Effet sur la desserte** : taux avant / après, distance moyenne, nombre de classes estimé pour une école.
6. **Placer un site** (clic sur la carte), **glisser** un site pour le déplacer, **Réévaluer**.
7. **Enregistrer comme scénario** ; dans la liste des scénarios : charger, préparer le **dossier** signé, **valider** / **archiver** (Responsable), supprimer (non validé).

Méthode : [Aide à l'implantation](../methodes/implantation.md).
