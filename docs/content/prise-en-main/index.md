# Prise en main

## Se connecter

Ouvrez la console (https://localhost ou l'adresse de votre instance), saisissez votre identifiant et votre mot de passe. À la première connexion, un nouveau mot de passe est exigé (12 caractères, 3 familles de caractères). Les comptes sont créés par un administrateur (Administration → Utilisateurs).

## Naviguer

Le bandeau du haut donne accès aux écrans. Ceux qui portent sur **une commune** (Commune, Atlas, Décision, Veille, Équipements) affichent un **sélecteur de commune** en haut à droite ; la coche ✓ signale les communes dont l'analyse satellitaire est disponible. La commune choisie est mémorisée.

| Écran | Pour quoi faire |
| --- | --- |
| [Territoire](../ecrans/territoire.md) | comparer les 22 communes sur un indicateur (carte et classement) |
| [Commune](../ecrans/commune.md) | la fiche statistique complète, la croissance du bâti, la desserte |
| [Atlas](../ecrans/atlas.md) | la carte multi-couches au carreau de 200 m, synchronisée avec l'imagerie de chaque année |
| [Décision](../ecrans/decision.md) | proposer et comparer des sites d'implantation, enregistrer des scénarios |
| [Veille](../ecrans/veille.md) | les quartiers qui ont grandi, la liste à transmettre à l'INSEE |
| [Équipements](../ecrans/equipements.md) | l'inventaire, et la saisie des équipements manquants ou en projet |
| [Analyses](../ecrans/analyses.md) | lancer les analyses satellitaires, synchroniser les données ouvertes |
| [Rapports](../ecrans/rapports.md) | le registre des documents signés |

Le badge **Charte 200 m** (dans le tiroir ☰ et le menu du compte sur petit écran) ouvre la [charte d'usage](../ethique.md). Le lien **Documentation** ouvre cette base de connaissances.

L'interface est commune aux plateformes de la famille : même bandeau, mêmes écrans de connexion, d'audit et d'administration des comptes. Sur grand écran, chaque écran est une icône du bandeau (son nom s'affiche au survol ; celui de l'écran ouvert est écrit en toutes lettres). Sur téléphone ou tablette étroite, le bouton **☰** ouvre un tiroir qui liste les écrans avec leur description. La touche **Échap** ferme menus et fenêtres ; **Tab** fait apparaître le lien « Aller au contenu ».

## Première utilisation d'une commune

1. **Analyses** → bouton **Analyser** sur la commune (quelques minutes). Le journal montre chaque étape.
2. **Atlas** : couche *Surface bâtie gagnée* depuis 2019, puis *Accessibilité* → *École*.
3. **Décision** : choisir l'équipement, le nombre de sites, puis **Proposer**.
4. **Veille** : relire les quartiers en croissance et, si besoin, exporter la liste Recensement Éclaireur.

!!! info "Démarrage sans réseau"
    Une instance neuve charge un **instantané** des données ouvertes et des analyses déjà réalisées (Saint-Laurent-du-Maroni, Cayenne, Matoury, Kourou, Macouria, Mana, Maripasoula, Apatou, Grand-Santi). Elle fonctionne donc hors ligne pour une démonstration ; **Analyses → Synchroniser** met tout à jour dès que le réseau est disponible.
